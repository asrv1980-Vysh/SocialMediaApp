# Social Media Android Application

## Project Overview

This project is a Social Media Android Application developed as part of my Android Development Internship.

The application allows users to register, login, view posts, create posts, interact with posts, search users, manage their profile, and logout.

## Technologies Used

- Java
- XML
- Android Studio
- Android SDK

## Features

### User Authentication
- User Registration
- User Login
- User Logout

### Home Feed
- View user posts
- Image/Video section
- Post captions
- Post timestamps
- Like posts
- Comment on posts
- Follow users

### Create Post
- Select Image/Video
- Add caption
- Publish post

### Profile
- View profile details
- Edit profile
- Update profile
- View followers and following count
- View uploaded posts

### Search
- Search users by username

## Project Structure

- MainActivity.java - Welcome screen
- LoginActivity.java - Login screen
- SignupActivity.java - Registration screen
- HomeActivity.java - Home feed
- CreatePostActivity.java - Create post
- ProfileActivity.java - User profile
- SearchActivity.java - Search users

## How to Run

1. Open the project in Android Studio.
2. Allow Gradle synchronization to complete.
3. Select an Android Emulator or connected Android device.
4. Click the Run button.
5. The Social Media Application will launch.
